# Sept créations en une soirée

Sept pages autonomes autour du Mali et de l'Afrique de l'Ouest. Chaque dossier contient un seul fichier `index.html`, sans étape de construction.

| Dossier | Création |
|---|---|
| `tombouctou/` | Tombouctou vers 1500 en 3D, avec une quête |
| `bamako-2150/` | Court-métrage animé d'une minute, et sa version vidéo |
| `caravane/` | Jeu de gestion : le pèlerinage de Mansa Moussa en 1324 |
| `awale/` | Awalé contre l'ordinateur ou à deux |
| `studio/` | Kora et balafon jouables, avec enregistreur de boucles |
| `atelier/` | Générateur de tissus bogolan, wax et kente |
| `trou-noir/` | Simulation interactive d'un trou noir |

Le site est statique : il suffit de servir le dossier tel quel.
